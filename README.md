# 🌡️ Conversor de Temperatura em Python

Projeto acadêmico desenvolvido durante o curso de **Ciência da Computação**, com o objetivo de praticar operações matemáticas, entrada de dados e conversão de tipos utilizando Python.

## 📌 Sobre o projeto

O projeto consiste em um programa simples que realiza a **conversão de temperaturas de Celsius para Fahrenheit**.

O usuário informa uma temperatura em graus Celsius e o programa realiza o cálculo utilizando a fórmula:

**Fahrenheit = (Celsius × 9/5) + 32**

Após realizar a conversão, o resultado é apresentado ao usuário no terminal.

## 🛠️ Tecnologias utilizadas

* Python
* Visual Studio Code

## 📚 Conceitos praticados

Durante o desenvolvimento do projeto, foram utilizados e praticados conceitos como:

* Variáveis
* Entrada e saída de dados
* Conversão de tipos (`float`)
* Operações matemáticas
* Fórmulas de conversão
* F-strings
* Exibição de resultados no terminal

## ▶️ Como executar

1. Certifique-se de ter o **Python** instalado em seu computador.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto no **Visual Studio Code** ou em outro editor de código.
4. Execute o arquivo:

```bash
python conversor_temperatura.py
```

5. Digite uma temperatura em graus Celsius quando solicitado.

6. O programa exibirá a temperatura correspondente em Fahrenheit.
